# Python 进阶小课堂

这是一套面向 Python 零基础前端开发工程师的 28 天课程。每天约 4 小时，目标是能独立完成常见 Python Web 业务开发、测试与交付。

每节课不是知识点摘要，而是一套完整教学单元：学习背景、前置术语、连续章节、可运行示例、逐行执行说明、前端经验类比、理解检查、常见错误、递进练习、完整代码任务和随堂测验。

## 快速开始

1. 双击 `启动小课堂.command`。
2. 浏览器会打开 `http://127.0.0.1:4173`。
3. 按顺序学习知识点、完成代码任务、提交随堂测验。
4. 关闭启动脚本所在的终端窗口即可停止服务。

也可以在终端运行：

```bash
cd "/Users/haoenxu/Desktop/Python进阶小课堂"
npm start
```

## Python 开发环境

课程使用目录内的 `.venv`，不会修改全局 Python：

```bash
source .venv/bin/activate
python --version
pytest --version
ruff --version
```

退出虚拟环境：

```bash
deactivate
```

## 文件说明

- `Python_28天进阶大纲.md`：完整课程目标、日程、练习和验收标准。
- `练习题与项目说明.md`：阶段练习、综合项目和自测方法。
- `环境检查报告.md`：本机运行环境与已安装工具。
- `练习代码/`：每天编写代码的位置，附带起步说明。
- `public/`：本地小课堂前端。
- `server.js`：零依赖 Node 静态服务。

## 学习约定

- 浏览器中的进度保存在本机 localStorage，清除浏览器数据会重置。
- 随堂测验用于即时纠错，代码任务仍需在编辑器和终端中运行。
- 不在网页里直接执行任意 Python 代码，避免本地文件被误操作。
